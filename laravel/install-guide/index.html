Installation Guide

Installing, Updating and Running Reactive Shop (Laravel)

Learn how to deploy Reactive Shop on any standard cPanel, Shared Hosting, Plesk, or Cloud VPS server with PHP 8.3+ and MySQL/MariaDB in under 5 minutes.

1

Server requirements

Standard modern PHP hosting requirements.

Reactive Shop runs smoothly on virtually any shared or managed hosting provider (cPanel, Namecheap, Hostinger, SiteGround, DigitalOcean, Hetzner, AWS, etc.).

  • PHP Version: PHP 8.3 or newer (8.4 and 8.5 work too)
  • Database: MySQL 8.0+ or MariaDB 10.4+
  • PHP Extensions: pdo_mysql, mbstring, openssl, tokenizer, xml, ctype, json, bcmath, fileinfo, curl, sodium (standard in default PHP installations).
  • Memory Limit: 128 MB or higher
2

Uploading & Permissions

Placing files on your hosting account.

  1. Upload the unzipped contents to your web server root (e.g. /home/username/public_html or your application folder).
  2. Ensure the web server points its Document Root to the public/ folder.
  3. Ensure the following folders are writable (permissions 775 or 755): 
    chmod -R 775 storage bootstrap/cache
3

Web server configuration

Apache (.htaccess) or Nginx URL rewriting.

Apache (cPanel & standard hosting)

The included public/.htaccess handles routing automatically. Ensure mod_rewrite is enabled.

Nginx

If configuring an Nginx virtual host, set the root to the public directory and add:

location / {
    try_files $uri $uri/ /index.php?$query_string;
}
4

The Web Installer (/setup.html)

Automated web browser installation.

When you visit your domain for the first time, navigate to https://yourdomain.com/setup.html:

  1. Setup Token: Enter the one-time token generated in storage/setup-token.txt or your configured SHOP_SETUP_TOKEN.
  2. License: Enter your CodeCanyon purchase code to activate your license. (Localhost, *.test, and staging addresses activate automatically).
  3. Database: Enter your database credentials (Host, Port, DB Name, User, Password). The installer automatically creates tables and loads the demo catalog.
  4. Admin Account: Set your shop name, admin full name, email, and password (minimum 12 characters).
Permanent Security Lock: Once setup completes, the setup wizard locks permanently.
5

Command Line Alternative

For developers and CI/CD pipelines.

cp .env.example .env
php artisan key:generate
# Configure DB_DATABASE, DB_USERNAME, DB_PASSWORD in .env
php artisan migrate --seed
php artisan shop:refresh-rates
6

Background scheduler (Cron)

Automatic payment reconciliation, exchange rates, and cart cleanup.

Add a single cron entry to your server's crontab (or cPanel Cron Jobs):

* * * * * cd /path-to-your-shop && php artisan schedule:run >> /dev/null 2>&1
7

Updating the shop

Zero-downtime upgrades for new releases.

When a new version is released:

  1. Upload and overwrite the shop files (except .env and storage/).
  2. Visit https://yourdomain.com/update.html and click Run Database Update (or sign in as admin and run).
  3. Or via terminal: php artisan migrate --force
8

FAQ & Troubleshooting

Answers to common deployment questions.

Why am I getting a 500 error on first upload?

Check that storage/ and bootstrap/cache/ permissions are writable (775), and that .env exists.

Where are payment gateway settings configured?

Sign in to your admin panel and go to Admin → Integrations to configure M-Pesa Daraja, Pesapal 3.0, PayPal, Stripe, and SMTP credentials directly with credential testing buttons.
